Literal-waveform variant of shot 105084.

Preprocesses the same real DINA source (/work/imas/shared/imasdb/ITER/3/105084/1) as the
105084 scenario -- same boundary shape, machine description, and ECRH heating -- but under
its own SHOT_NR ("105084_literal") so it gets its own tmp/data/ output and can carry its own
waveforms.yaml override.

That waveforms.yaml drops the {ref: input} import for the equilibrium ip/r0/b0 and
core_profiles ip targets and replaces them with explicit analytic tendencies (constant /
piecewise) whose numbers mirror the actual 105084 reference trace, so the pulse design is
readable directly in the YAML instead of pointing at an external IDS. The boundary outline
(r/z) stays {ref: input}: it is a variable-length per-slice spatial array (168-310 points in
105084), and Waveform-Editor's tendency system only ever produces one scalar per time step --
there is no literal-array waveform type, so an import is the only way to populate it.
