# Prepared scenario data

Default data root for prepared scenarios (`SCENARIOS_REPO`). Everything here is
generated by `bin/pds-configure --prepare` / `preprocessing/prepare` from
`cases/pulses/<shot>.yaml` and is not committed. Point `SCENARIOS_REPO` elsewhere
(e.g. `/work/projects/pds/pds-scenarios`) to use another data root.

See [`preprocessing/README.md`](../preprocessing/README.md) for the preparation guide.
